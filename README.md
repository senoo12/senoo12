### 🚀 What I'm Working On

| Project | Description |
|---|---|
| 🖋️ **Letter Template Generator** | Fullstack letter generation system — Go backend, Svelte frontend, image embedding support |
| 🎨 **Batik Banyumasan Colorization** | Pix2Pix-style GAN (U-Net Generator + PatchGAN Discriminator, LSGAN Loss) for automatic batik pattern colorization |
| 🌱 **Food Sustainability Classifier** | Fine-tuned IndoBERT model classifying sustainability awareness from Indonesian Twitter data, served via FastAPI + Go gateway |
| 🛰️ **Urban Semantic Segmentation** | UNet++ with InceptionResNetV2 backbone for land-cover segmentation on Pleiades satellite imagery |
| 🧭 **Institutional Navigation App** | Web-based routing app using Go/Gin, Supabase, Firebase Auth, and graph algorithms (A*, Dijkstra, Bellman-Ford) |
